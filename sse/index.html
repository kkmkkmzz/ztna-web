SSE · Security Service Edge

SSE란 무엇인가요

직원이 어디서 무엇에 접속하든, 클라우드에 있는 하나의 보안 검문소를 거치게 하는 서비스 묶음입니다.

비유로 이해하기

공항 보안 검색대를 떠올려 보세요. 국내선(사내 앱)을 타든, 국제선(인터넷)을 타든, 면세점(클라우드 앱)에 가든 같은 검색대를 통과합니다. 검색대가 하나라서 기준도 하나입니다.

어떤 문제를 해결하나요

흩어진 장비

웹 필터, 클라우드 앱 통제, 원격 접속 장비가 따로 있어 정책이 서로 어긋납니다.

사무실 밖 사용자

재택이나 출장 중 트래픽은 회사 보안 장비를 거치지 않습니다.

클라우드 앱 정보 유출

개인 클라우드 계정에 회사 파일을 올려도 알기 어렵습니다.

어떻게 동작하나요

  1. 가까운 검문소로기기의 에이전트나 설정이 트래픽을 가장 가까운 클라우드 검문소로 보냅니다.
  2. 목적지 구분인터넷 사이트인지, 클라우드 앱인지, 사내 앱인지 구분합니다.
  3. 종류별 검사인터넷은 SWG, 클라우드 앱은 CASB, 사내 앱은 ZTNA가 검사합니다.
  4. 같은 정책 적용어디로 가든 같은 기준으로 허용, 경고, 차단합니다.
  5. 기록 한곳에모든 기록이 한곳에 모여 보안 운영팀이 볼 수 있습니다.

직접 해 보기: 트래픽은 어디를 거쳐 갈까

직원이 하는 행동을 하나 골라 보세요. SSE가 목적지에 따라 어떤 검사를 거치게 하는지 보여 줍니다.

시뮬레이션: 가상의 상황과 데이터로 만든 예시이며, 실제 제품의 정책이나 성능이 아닙니다.

핵심 기능

SWG (웹 접속 검사)

악성 사이트나 업무와 무관한 위험 사이트 접속을 막습니다.

CASB (클라우드 앱 통제)

어떤 클라우드 앱을 누가 쓰는지 보고, 위험한 사용을 제한합니다.

ZTNA (사내 앱 접근)

확인된 사람과 기기만 필요한 사내 앱에 연결합니다.

DLP (정보 유출 방지)

주민등록번호 같은 민감 정보가 밖으로 나가는 것을 감지합니다.

자주 헷갈리는 질문

SSE와 SASE는 무엇이 다른가요?

SASE는 SSE의 보안 기능에 지사와 본사를 잇는 네트워크 기능(SD-WAN)까지 합친 더 넓은 개념입니다. 간단히 SASE = SSE + 네트워크라고 기억하면 됩니다.

SSE와 ZTNA는 같은 건가요?

아닙니다. ZTNA는 SSE 안에 들어 있는 기능 중 하나입니다. SSE는 ZTNA에 웹 검사, 클라우드 앱 통제 등을 더한 묶음입니다.

회사에 방화벽이 있으면 SSE가 필요 없나요?

사무실 방화벽은 사무실을 지나는 트래픽만 봅니다. 사무실 밖에서 바로 인터넷과 클라우드 앱으로 가는 트래픽을 같은 기준으로 보려는 것이 SSE의 목적입니다.

모든 트래픽을 검사하면 개인정보는 괜찮나요?

검사 범위를 어디까지 둘지는 회사 정책과 법적 요건에 따라 정해야 합니다. 금융·의료 사이트처럼 검사에서 제외하는 범위를 따로 두는 경우가 많습니다.
